# Conexão Game SEO - Eudemons Online Website

Um portal/website completo desenvolvido em Arquitetura MVC voltado para a comunidade do jogo Eudemons Online, com foco em otimização para motores de busca (SEO), performance e experiência do usuário.

---

## Links do Projeto

- Website Oficial: https://conexaogameseo.com
- Página Inicial: https://conexaogameseo.com/home

---

## Sobre o Projeto

O projeto foi construído para servir como a plataforma principal de informações, guias, serviços e recursos para jogadores de Eudemons Online. Todo o sistema foi desenhado do zero utilizando o padrão MVC (Model-View-Controller) para garantir modularidade, facilidade de manutenção e segurança.

---

## Principais Funcionalidades

- Design Responsivo: Adaptado para computadores, tablets e smartphones.
- Otimização para SEO: Estruturado com meta tags dinâmicas, URLs amigáveis e marcações semânticas para melhor posicionamento nos buscadores.
- Painel/Gerenciamento: Separação clara entre a lógica de negócios, interface visual e manipulação de dados.
- Integração com Servidor/API: Gerenciamento de informações e recursos voltados a Eudemons Online.

---

## Tecnologias e Arquitetura

- Padrão de Arquitetura: MVC (Model-View-Controller)
- Back-end: PHP
- Banco de Dados: MySQL
- Front-end: HTML5, CSS3, JavaScript, jQuery
